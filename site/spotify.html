1Connect Spotify

Sign in to the Spotify account you want to copy into. Crate talks to Spotify straight from this browser; nothing goes through any other server.

2Find your songs on Spotify

Each song is looked up by title, artist and album. Spotify limits how fast this can go, so a few thousand songs take a while; you can leave this tab open, and if it gets closed it picks up where it left off.

3Review the matches

Exact matches are used as they are. Close matches are used too unless you pick something else or skip them, so they're worth a look. Not found songs can be searched by hand.

4Send to Spotify

Playlists to recreate

Playlists are created as private playlists with the same name and order; songs without a match are left out. Running this again only adds what's missing, so it's safe after changing picks or finding more songs (late additions go at the end of a playlist).
