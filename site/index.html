Crate Playlist Builder

Browse your Apple Music library as Artist → Album → Song, tick what you want, and build a playlist from it.

  1. 1In Music on your Mac: File → Library → Export Library… and save the XML.
  2. 2Load that file here, or drag it onto this page. It stays in your browser and isn't uploaded.
  3. 3Tick artists, albums or songs. Optionally start from one of your existing playlists.
  4. 4Copy the script, paste it into Script Editor, and press Run.
