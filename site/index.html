How Crate works

  1. 1In Music on your Mac: File → Library → Export Library… and save the XML.
  2. 2Load that file here, or drag it onto this page. It stays in your browser, isn't uploaded, and is remembered here along with your edits.
  3. 3Pick or start playlists on the left, then tick artists, albums or songs on the right. Switch between playlists any time.
  4. 4Press Review & apply, copy the script, paste it into Script Editor, and press Run.

Editing on your iPhone too

  1. Mac: export the library into iCloud Drive (in the save dialog pick iCloud Drive, e.g. a “Crate” folder, and keep the name Library.xml).
  2. iPhone: open this page, tap Load library file → Browse → iCloud Drive → Library.xml. The phone remembers it after that.
  3. iPhone: edit playlists as usual. Tap Review & apply, then Share script → AirDrop → your Mac.
  4. iPhone: tap Mark as applied, so the next script from the phone only carries newer edits.
  5. Mac: double-click the script in Downloads to open it in Script Editor, then press Run.
  6. Getting the changes into Music on the iPhone: with Sync Library on (needs Apple Music or iTunes Match), iCloud updates the phone's playlists within a few minutes. Without it, sync the iPhone in Finder: select it in the sidebar → Music → choose the playlists → Sync. Ticking Show this iPhone when on Wi-Fi under General lets you sync without a cable.
  7. Afterwards: the script saves an updated Library.xml to iCloud Drive › Crate (if that box is ticked). Load it on each device: changes you've already run show as done, and edits you haven't run yet are kept.

Scripts only add and remove the songs you changed, so edits made on the Mac and the iPhone can be run in any order. If both devices change the same song in opposite ways, the script run last wins.

Running the script

  1. Open Script Editor (Applications → Utilities).
  2. New document, paste, press Run ▶. Or download the script and double-click it.
  3. Allow it to control Music if macOS asks. The script only adds the songs you ticked (at the end) and removes the ones you unticked, so it's safe to run scripts from several devices, or the same one twice.
  4. On a phone: Share script → AirDrop to your Mac, then Mark as applied so the next script only has newer changes.
Set up the Crate shortcut (once)

Add with Shortcuts adds songs to your changed playlists (creating new ones) right on this device, without the Mac. With Sync Library on, the change reaches your other devices. It does the additions for every playlist with changes; any removals or renames stay pending for the Mac script, or doing by hand in Music.

Get the shortcut from iCloud and tap Add Shortcut (delete any older Crate Add Songs first). Or open the setup guide to import the file with your Mac, or build it yourself; the short version is below.

In the Shortcuts app, tap + and name the new shortcut exactly Crate Add Songs. Then add these actions in order (tap a blue field to pick a variable):

  1. Get Dictionary from Input, input: Shortcut Input. Version check: Get Dictionary Value need_v5; If it has any value: Text v4 outdated, Stop and Output it. End If. Then Get Dictionary Value: Value for songs in Dictionary.
  2. Repeat with Each item in that value. Inside the repeat:
    1. Get Dictionary Value playlist in Repeat Item → Set Variable Playlist Name.
    2. Get Dictionary Value create in Repeat Item. If it has any value: Create Playlist named Playlist Name, then Wait 3 seconds. End If.
    3. Get Dictionary Value title, artist, album in Repeat Item → Set Variable Title, Artist, Album.
    4. Find Music where Title is Title, Artist is Artist and Album is Album; Limit 1 → Set Variable Song.
    5. If Song does not have any value (a second try ignoring capitals): Text Artist|Album → Change Case lowercase → Set Variable Key; Find Music where Title is Title; Repeat with Each: Get Details of Music Artist and Album of Repeat Item 2, Text Artist|Album, Change Case lowercase, If it is Key: Set Variable Song to Repeat Item 2. End Repeat. End If.
    6. If Song has any value: Add to Playlist, adding Song to Playlist Name. Otherwise: Get Dictionary Value index in Repeat Item, then Add to Variable Missing. End If.
  3. After End Repeat: Combine Text Missing with Custom separator ,; Text v4 missing: followed by Combined Text; Stop and Output that text. (The v4 tells Crate which version you have, so it can say when there's a newer one.)

Songs are matched by title, artist and album, so the first run is worth checking in Music. If Shortcuts asks for permission to use your music library, allow it.
