Crate Shortcut Setup

← Back to Crate

How to get the Crate Add Songs shortcut onto your iPhone or iPad. You only do this once. Afterwards, Crate's Add with Shortcuts button adds songs to your playlists right on the phone, without the Mac.

Easiest: install it from iCloud (version 3)

  1. 1
    If you have an older Crate Add Songs, delete it first (press and hold it in Shortcuts → Delete), so the new one keeps the exact name Crate uses.
  2. 2
    On your iPhone or iPad, tap:
    Get Crate Add Songs
    Shortcuts opens and shows the shortcut. Tap Add Shortcut.
  3. 3
    Do the first run below. With iCloud sync on in Shortcuts, it also appears on your other devices.

or, with your Mac:

Import the shortcut file (needs your Mac)

Instead of building it by hand, download the shortcut file, have your Mac sign it (Apple only imports signed shortcuts), and add it.

  1. 1
    On your Mac, first delete any older crate-add-songs-unsigned files and Crate Add Songs.shortcut from Downloads. Otherwise the browser saves the new one as crate-add-songs-unsigned-2.shortcut (or similar) and step 2 signs the old one. Then download the file:
    Download crate-add-songs-unsigned.shortcut
  2. 2
    Open Terminal (Applications → Utilities), paste these two lines and press Return:
    cd ~/Downloads shortcuts sign --mode anyone --input crate-add-songs-unsigned.shortcut --output "Crate Add Songs.shortcut"

    It takes a few seconds and prints nothing when it works. The new file's name becomes the shortcut's name, so keep it as Crate Add Songs.shortcut.

  3. 3
    In Finder, double-click Crate Add Songs.shortcut in Downloads, then click Add Shortcut.
    • If Shortcuts syncs through iCloud (on the iPhone: Settings → Apps → Shortcuts → iCloud Sync), it appears on your phone within a minute or so.
    • Otherwise, AirDrop the signed file to your iPhone and tap Add Shortcut there.
  4. 4
    Open it in Shortcuts and compare it with the steps below, especially the two If actions (steps 8 and 12), the conditions in both Find Music actions (steps 11 and 12), the If … is Key in step 12 and the playlist in Add to Playlist (step 13). If an action has a blank that didn't come through, fill it in as the steps describe.

Updating? This is version 3 of the shortcut. When Crate says yours is out of date, delete the old Crate Add Songs on every device, and any old copies of the file in Downloads, then install this one (or use the iCloud link above).

This file was written by hand from Shortcuts' file format and hasn't been tested on a device yet. If signing reports an error, or parts are missing after importing, note the details.

or build it yourself:

How the Shortcuts editor works

  • Adding an action: tap the Search Actions bar at the bottom of the editor, type the action's name, and tap it. New actions are added at the bottom of the shortcut.
  • Moving an action: press and hold its title, then drag it where you want. You'll need this to put actions inside an If or Repeat block.
  • Blue words in an action are blanks. Tap one to type a value or pick a variable.
  • Picking a variable: when you tap a blank, a bar of variables appears just above the keyboard; tap the one you want. If it isn't there, tap Select Variable, then tap the earlier action whose result you want (it lights up).
  • Why there are named variables: several actions produce a result called "Dictionary Value", which is hard to tell apart, so these steps save them under clear names with Set Variable.

These steps describe the Shortcuts app on iOS 18. On other versions some labels may be worded slightly differently.

Create the shortcut

  1. 1
    Open Shortcuts and tap + at the top right.
  2. 2
    Tap the name at the top ("New Shortcut") → Rename → type Crate Add Songs exactly → Done. Crate calls the shortcut by this name.

Part 1: read what Crate sends

Crate sends one list of songs, covering every playlist you're adding to. Each song says which playlist it goes in.

  1. 3
    Add Get Dictionary from Input. Tap the blue Input → choose Shortcut Input.

    A line saying "Receive Any input from Nowhere" may appear at the top. Leave it as it is.

  2. 4
    Add Get Dictionary Value. It reads "Get Value for Key in Dictionary". Tap Key → type songs.
  3. 5
    Add Repeat with Each. It should say "Repeat with each item in Dictionary Value", and comes with End Repeat.

Steps 6–13 all go inside the Repeat: after adding each action, drag it up above End Repeat, keeping this order.

Part 2: the song's playlist (inside the Repeat)

  1. 6
    Get Dictionary Value: Key → playlist; Dictionary → choose Repeat Item from the variable bar. Then Set Variable → name it Playlist Name.
  2. 7
    Get Dictionary Value: Key → create; Dictionary → Repeat Item.
  3. 8
    If: the first blank should say Dictionary Value. Tap Condition → choose has any value. (Crate only sends create with the first song of a playlist that needs making.) It comes with Otherwise and End If.
  4. 9
    Between If and Otherwise: add Create Playlist and tap its name blank (it may say Playlist Name or Name) → pick the variable Playlist Name. Then add Wait under it and set it to 3 seconds: a brand-new playlist can't be found by name straight away, so without the pause the songs have nowhere to go.

Part 3: find the song and add it (still inside the Repeat, after End If)

  1. 10
    Get Dictionary Value title in Repeat Item → Set Variable Title. Do the same for artist → Artist and album → Album.
  2. 11
    Find Music:
    • Tap Add Filter → set it to Title is → tap the value → pick the variable Title.
    • Add Filter → Artist is → Artist.
    • Add Filter → Album is → Album.
    • Turn on Limit and set it to Get 1 Song.
    Then Set Variable → name it Song (its input is Music).
  3. 12
    A second try that ignores capitals, because the phone can show an album or artist capitalised differently from your Mac ("The Lion the Beast the Beat" vs "The Lion The Beast The Beat") and Find Music's is counts that as different. Add If: Song does not have any value. Between If and Otherwise:
    • Text: tap Artist in the variable bar, type |, tap Album. Then Change Case → lowercase, and Set Variable Key.
    • Find Music with one filter, Title is Title, and no limit.
    • Repeat with Each item in Music. Inside it:
      • Get Details of Music: Artist of Repeat Item 2, and another for Album of Repeat Item 2.
      • Text: the Artist detail, |, the Album detail. Then Change Case → lowercase.
      • If Updated Text is Key: Set Variable Song to Repeat Item 2. End If.
    Leave its Otherwise empty.
  4. 13
    If: Song has any value.
    • Between If and Otherwise: add Add to Playlist. It reads "Add Music to Playlist". Tap the first blank → the variable Song; tap Playlist → the variable Playlist Name.
    • Between Otherwise and End If: add Get Dictionary Value: Key → index; Dictionary → Repeat Item. Then add Add to Variable: tap Variable Name → type Missing.

Part 4: report back to Crate

These go after End Repeat, at the bottom.

  1. 14
    Combine Text: tap its input → pick the variable Missing. Tap New Lines → Custom → type a comma ,
  2. 15
    Text: in its box, type v3 missing: (with a space after v3) and then, right after the colon with no space, tap Combined Text in the variable bar.
  3. 16
    Stop and Output: its input should be Text. If it asks what to do when there's nowhere to output, leave it on Do Nothing.

Tap Done to save.

First run

In Crate on your phone, tick one song to add to a test playlist and tap Add 1 song with Shortcuts.

  • Shortcuts may ask permission to use your music library, and later to open a web page to go back to Crate. Allow both.
  • Back in Crate, the message should say the song was added. Check the playlist in the Music app.

If something doesn't work

  • The variable won't go in at step 9 or step 13: if the Playlist blank won't accept a variable, note what it offers instead.
  • Songs come back "not found" even though they're in your library: try removing the Album filter in step 11.
  • Shortcuts shows an error: first make sure you have the current version (step 15's text should start v3), then note which step it highlights, if any.
