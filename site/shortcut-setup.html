Crate Shortcut Setup

← Back to Crate

Step-by-step instructions for building the Crate Add Songs shortcut on your iPhone or iPad. You only do this once. Afterwards, Crate's Add with Shortcuts button adds songs to your playlists right on the phone, without the Mac.

Quick way: import a ready-made shortcut (needs your Mac)

Instead of building it by hand, download the shortcut file, have your Mac sign it (Apple only imports signed shortcuts), and add it.

  1. 1
    On your Mac, download the file:
    Download crate-add-songs-unsigned.shortcut
  2. 2
    Open Terminal (Applications → Utilities), paste these two lines and press Return:
    cd ~/Downloads shortcuts sign --mode anyone --input crate-add-songs-unsigned.shortcut --output "Crate Add Songs.shortcut"

    It takes a few seconds and prints nothing when it works. The new file's name becomes the shortcut's name, so keep it as Crate Add Songs.shortcut.

  3. 3
    In Finder, double-click Crate Add Songs.shortcut in Downloads, then click Add Shortcut.
    • If Shortcuts syncs through iCloud (on the iPhone: Settings → Apps → Shortcuts → iCloud Sync), it appears on your phone within a minute or so.
    • Otherwise, AirDrop the signed file to your iPhone and tap Add Shortcut there.
  4. 4
    Open it in Shortcuts and compare it with the steps below, especially the two If actions (steps 7 and 15), the three conditions in Find Music (step 14) and the playlist in Add to Playlist (step 16). If an action has a blank that didn't come through, fill it in as the steps describe.

This file was written by hand from Shortcuts' file format and hasn't been tested on a device yet. If signing reports an error, or parts are missing after importing, note the details.

or build it yourself:

How the Shortcuts editor works

  • Adding an action: tap the Search Actions bar at the bottom of the editor, type the action's name, and tap it. New actions are added at the bottom of the shortcut.
  • Moving an action: press and hold its title, then drag it where you want. You'll need this to put actions inside an If or Repeat block.
  • Blue words in an action are blanks. Tap one to type a value or pick a variable.
  • Picking a variable: when you tap a blank, a bar of variables appears just above the keyboard; tap the one you want. If it isn't there, tap Select Variable, then tap the earlier action whose result you want (it lights up).
  • Why there are named variables: several actions produce a result called "Dictionary Value", which is hard to tell apart, so these steps save them under clear names with Set Variable.

These steps describe the Shortcuts app on iOS 18. On other versions some labels may be worded slightly differently.

Create the shortcut

  1. 1
    Open Shortcuts and tap + at the top right.
  2. 2
    Tap the name at the top ("New Shortcut") → Rename → type Crate Add Songs exactly → Done. Crate calls the shortcut by this name.

Part 1: read what Crate sends

  1. 3
    Add Get Dictionary from Input. Tap the blue Input → choose Shortcut Input.

    A line saying "Receive Any input from Nowhere" may appear at the top. Leave it as it is.

  2. 4
    Add Get Dictionary Value. It reads "Get Value for Key in Dictionary".
    • Tap Key → type playlist.
    • Leave Dictionary as it is.
  3. 5
    Add Set Variable. Tap Variable Name → type Playlist Name. Its input should already show Dictionary Value.

Part 2: create the playlist if Crate asks

  1. 6
    Add another Get Dictionary Value.
    • Key → type create.
    • Tap Dictionary → Select Variable → tap the Get Dictionary from Input action (step 3).
  2. 7
    Add If. It appears together with Otherwise and End If.
    • The first blank should already say Dictionary Value.
    • Tap Condition → choose is.
    • Tap Text → type yes.
  3. 8
    Add Create Playlist.

    Drag it up so it sits between If and Otherwise.

    • Tap its name blank (it may say Playlist Name or Name) → pick the variable Playlist Name from the bar.

Part 3: go through the songs

  1. 9
    Add another Get Dictionary Value (it goes after End If).
    • Key → type songs.
    • Dictionary → Select Variable → tap the Get Dictionary from Input action again.
  2. 10
    Add Repeat with Each. It should say "Repeat with each item in Dictionary Value", and comes with End Repeat.

For steps 11–16: after adding each action, drag it up inside the Repeat, above End Repeat, keeping this order.

  1. 11
    Get Dictionary Value: Key → title; Dictionary → choose Repeat Item from the variable bar.
    Then Set Variable → name it Title.
  2. 12
    Get Dictionary Value: Key → artist; Dictionary → Repeat Item.
    Then Set Variable → Artist.
  3. 13
    Get Dictionary Value: Key → album; Dictionary → Repeat Item.
    Then Set Variable → Album.
  4. 14
    Find Music:
    • Tap Add Filter → set it to Title is → tap the value → pick the variable Title.
    • Add Filter → Artist is → Artist.
    • Add Filter → Album is → Album.
    • Turn on Limit and set it to Get 1 Song.
  5. 15
    If: the first blank should be Music (Find Music's result). Condition → has any value.
  6. 16
    Fill in that If block:
    • Between If and Otherwise: add Add to Playlist. It reads "Add Music to Playlist". Tap Playlist → pick the variable Playlist Name.
    • Between Otherwise and End If: add Get Dictionary Value: Key → index; Dictionary → Repeat Item. Then add Add to Variable: tap Variable Name → type Missing.

Part 4: report back to Crate

These go after End Repeat, at the bottom.

  1. 17
    Combine Text: tap its input → pick the variable Missing. Tap New Lines → Custom → type a comma ,
  2. 18
    Text: in its box, type missing: and then, right after the colon with no space, tap Combined Text in the variable bar.
  3. 19
    Stop and Output: its input should be Text. If it asks what to do when there's nowhere to output, leave it on Do Nothing.

Tap Done to save.

First run

In Crate on your phone, tick one song to add to a test playlist and tap Add 1 song with Shortcuts.

  • Shortcuts may ask permission to use your music library, and later to open a web page to go back to Crate. Allow both.
  • Back in Crate, the message should say the song was added. Check the playlist in the Music app.

If something doesn't work

  • The variable won't go in at step 8 or step 16: if the Playlist blank won't accept a variable, note what it offers instead.
  • Songs come back "not found" even though they're in your library: try removing the Album filter in step 14.
  • Shortcuts shows an error: note which step it highlights, if any.
